   # Shinoblox

   Jogo de ação ninja para Roblox, desenvolvido pela **Ratworks**.

   ## Sobre
   RPG ninja com combate estilo anime, dungeons cooperativas com cartas
   e árvore de habilidades elemental.

   ## Como rodar o projeto
   1. Instale o Roblox Studio, o Git e o Rokit.
   2. Clone este repositório.
   3. Rode `rokit install` para instalar a versão certa do Rojo.
   4. Rode `rojo serve` na pasta do projeto.
   5. No Studio, conecte pelo plugin do Rojo.
